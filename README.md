# 레트로 달력 제작기
https://editor0518.github.io/RetroCalendarMaker/

관공서나 옛날에 쓰일법한 레트로 스타일의 달력을 만들 수 있는 사이트입니다.
상업적 용도로 사용하고자 하는 창작자들이 특정 년도의 옛날 달력 이미지를 찾는 수고를 덜 들이게 하고자 제작되었습니다.

## 광고
이 사이트는 제가 만들고 있는 게임 '비리검사 공재헌'의 법정 배경에 사용할 레트로 스타일 달력을 만들고자 제작한 김에 배포하였습니다.
